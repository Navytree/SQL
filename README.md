## General info
This repository contains various databases built from scratch along with SQL queries designed for data analysis. 
It serves as a personal portfolio showcasing my database design and query optimization skills.

## Technologies
* **Database Management Systems:** Microsoft SQL Server, MySQL

## Repository Structure
* `Microsoft SQL Server/` - Contains MSSQL database projects.
* `MySQL/`  - Contains MySQL database projects.

## Setup
Because this repository contains projects utilizing different Database Management Systems (MSSQL and MySQL), the environment setup varies. 

Please check the **README.md** inside the specific project folder for detailed, step-by-step instructions on how to restore the database and run the queries.
